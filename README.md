# nim-cli-spec

Clispec is a Nim library that turns one declarative description of a command
line into what a program needs to accept it: a typed configuration object, an
argv parser, help text, shell completion, optional layered loading of
configuration files, and a record of where each value came from.

The library has not been published here yet. This commit creates the `dev`
branch so the repository can be cloned and developed side by side with its
consumers.
